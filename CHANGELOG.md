# Changelog

## 1.0.0

First stable release of Comic Reader.

- Read-only local CBZ folder libraries with natural sorting, search, series details, and private lazy cover thumbnails.
- Vertical continuous reading and seamless chapter continuation with bounded extraction and archive cleanup.
- Saved positions, Continue Reading, page bookmarks, manual read states, and local JSON backup/import.
- Desktop zoom, phone fit-to-width and accessible overlay controls, fullscreen, shortcuts, page spacing, and OLED-black/dark/light backgrounds.
- True-black application styling, translucent reader controls, a compact mobile Show controls button, and immersive desktop fullscreen with global chrome hidden.
- Installable offline app shell, optional browser installation, user-controlled updates, and GitHub Pages deployment under `/comic-reader/`.
- Local IndexedDB storage, permission/error recovery, responsive keyboard-accessible UI, reduced motion, and safe-area support. Comic files are never modified or uploaded.
